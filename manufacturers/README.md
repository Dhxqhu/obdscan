# Manufacturer / DoIP packs

Selectable OEM libraries for enhanced DoIP/UDS (GT327 ethernet path).
These are **address scaffolds**, not dealer databases.

## Common brands (first-class IDs)

| ID | Brand |
|----|-------|
| `ford` | Ford |
| `lincoln` | Lincoln |
| `chevy` / `chevrolet` | Chevrolet |
| `gm` | General Motors (group) |
| `gmc` `cadillac` `buick` | GM brands |
| `dodge` `jeep` `ram` `chrysler` | Stellantis / FCA |
| `honda` `acura` | Honda |
| `nissan` `infiniti` | Nissan |
| `mazda` | Mazda |
| `toyota` `lexus` | Toyota |
| `hyundai` `kia` `genesis` | Hyundai Motor Group |
| `subaru` `mitsubishi` `suzuki` | JP |
| `bmw` `mini` | BMW |
| `mercedes` / `mb` | Mercedes-Benz |
| `vag` `vw` `audi` | VAG |
| `porsche` | Porsche |
| `volvo` `polestar` | Volvo |
| `jaguar` `landrover` | JLR |
| `tesla` `rivian` `lucid` | EV |
| `generic` | Any DoIP |

```bash
obdscan manufacturers
obdscan pack chevy
obdscan pack dodge
obdscan pack mazda
obdscan doip menu
```
